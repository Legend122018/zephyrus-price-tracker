Run it yourself

Grab a free Best Buy developer key — issued instantly at developer.bestbuy.com.

$ export BESTBUY_API_KEY=your_key_here

Unpack the tracker and write a config. No pip install — it is Python 3.11 standard library only.

$ tar xzf zephyrus-price-tracker.tar.gz && cd zephyrus-price-tracker
$ python3 -m zephyrus_tracker init

Check the key, confirm which Boston stores resolved, and see what it found.

$ python3 -m zephyrus_tracker check
$ python3 -m zephyrus_tracker stores
$ python3 -m zephyrus_tracker discover

Point alerts at your phone — pick an unguessable ntfy topic, subscribe to it in the ntfy app, and test the whole chain.

# config.toml
[notify.ntfy]
enabled = true
topic   = "zephyrus-bos-7f3a91"

$ python3 -m zephyrus_tracker test-alert

Then leave it running. Open-box units are single listings that often vanish within hours, so every 30 minutes is a sensible cadence.

$ python3 -m zephyrus_tracker watch --interval 30

Or use the included cron, systemd or GitHub Actions recipes — the Actions workflow runs on GitHub's machines and caches the price history, so you don't need an always-on computer.

Worth knowing

The numbers on this page are simulated. They demonstrate the interface and the alert logic. Real figures appear once you run a scan against the Best Buy API with your own key.
An API key is required, and there's no way around it. Best Buy's storefront is bot-protected; scraping it would be fragile and against their terms. The official API is the supported path, and it's free.
Open-box stock is reported nationally, not per store. Best Buy exposes open-box offers and their condition tiers, but not which store holds a given unit — so the pickup data in alerts is for the new listing.
The first scan is quiet by design. It has nothing to compare against yet, and the all-time-low rule needs three observations before it means anything.
Treat an alert as "go look now." API data can trail the website by a few minutes, which matters for a fast-moving open-box unit.
